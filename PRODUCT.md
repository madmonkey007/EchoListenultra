# EchoListen

## Platform
Web. Desktop and mobile browsers.

## Audience and task
Language learners bring their own audio and practice short sections repeatedly, read transcripts when available, and collect vocabulary. Optional Google login is for online allowance; local practice needs no login and local data should survive refresh.

## Product truth
Supports time-based local segmentation and optional Gemini/Deepgram transcription. Google account and server quota infrastructure are optional; platform-paid processing and video links remain disabled. No audio file export, cloud sync or subscriptions. Online transcription sends audio to a provider; local playback does not. Browser data can be cleared or evicted.

## Approved website scope
Public introduction, real example, library/player, help and clear API setup. Preserve learning functions and existing local data. English interface retained from existing product.
