How to use ReelTranscript

Follow a public Reel link through to a saved transcript.

Getting startedSave your resultYour dataTroubleshooting

Submit a public Instagram Reel

  1. Copy the link to a public Instagram Reel. The supported link identifies a Reel with an Instagram /reel/ path.
  2. Open the transcript tool, paste the link into the link field and start transcription. No sign-in is needed.
  3. Keep the page open while the progress indicator shows that the request is being processed.
  4. When the result appears, review the text alongside the original Reel.

Use only content you have permission to process. Private accounts, restricted Reels and ordinary Instagram photo or profile links are not supported.

Save the text or subtitles

Select Copy text to put the generated transcript on your clipboard, then paste it where you want to keep it.

Select Download SRT to save a subtitle file. An SRT contains numbered cues, each with a start time, an end time and its text. You can open it in a text editor or a compatible subtitle editor.

Save before refreshing

Submitted links and generated transcripts are not retained on the page after a refresh. Copy or download anything you want to keep before leaving or reloading.

A network connection is required to retrieve and transcribe the Reel. Read the privacy page for details about processing.

When a request cannot finish

  • If the link is rejected, check that it points to a Reel rather than a profile or another post type.
  • If the Reel cannot be retrieved, confirm it is still public and available. Instagram restrictions can prevent access even to a public post.
  • If the request exceeds the supported size or duration, choose a shorter Reel. The current duration limit is 60 seconds.
  • If the request fails unexpectedly, try again later or report the error. Include the steps and visible error message, without sensitive transcript text.
